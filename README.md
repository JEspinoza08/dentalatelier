# Dental Atelier - React + Vite

Proyecto convertido desde TanStack Start/Lovable a React + Vite estándar.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Estructura principal

- `index.html`: entrada HTML de Vite con metadatos SEO.
- `src/main.tsx`: monta React en `#root`.
- `src/App.tsx`: landing principal.
- `src/components/site`: secciones de la web.
- `src/assets`: imágenes del proyecto.

## Nota

Se retiraron archivos de TanStack Start/SSR como `src/routes`, `src/router.tsx`, `src/server.ts`, `src/start.ts`, `routeTree.gen.ts`, `wrangler.jsonc` y la configuración especial de Lovable/TanStack.
